# network-attack-pattern-analyzer

Detect abnormal network patterns from logs/packets







\## Problem

Modern network systems are vulnerable to stealthy attacks hidden in traffic logs.



\## Objective

Build a system to analyze network or telemetry data and classify:

\- Normal behavior

\- Suspicious patterns

\- Attack patterns



\## Scope

\- Parse network logs / packet data

\- Extract basic features (IP, ports, frequency)

\- Detect anomalies using rule-based logic (initial phase)

\- Extend to ML-based detection (future)

\- Integrate with UAV / IoT systems later



\## Tech Stack

\- Python

\- Scapy (for packet analysis)

\- Pandas (for data processing)
